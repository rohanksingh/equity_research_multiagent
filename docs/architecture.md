# 🏗️ Architecture

> Deep dive into the orchestration, state, and design of the
> **Equity Research Multi-Agent System**.

---

## 1. Design Philosophy

This system is a **hybrid pipeline**:

- **Deterministic core** — market data, rule-based scoring, portfolio math,
  consistency checks are all pure Python. No LLM. Reproducible.
- **LLM periphery** — only the final **explanation** is generated by the LLM.

Why? Because LLMs are bad at arithmetic and consistent labels, but good at
narrating structured facts. **Put the LLM where it adds value; keep the logic
where it's verifiable.**

```
┌───────────────────────────────────────────────────────────┐
│                  DETERMINISTIC CORE                       │
│  market ──► thesis ──► verifier ──► portfolio ──► checks  │
└───────────────────────────────────────────────────────────┘
                            │
                            ▼
┌───────────────────────────────────────────────────────────┐
│                     LLM PERIPHERY                         │
│                 explanation_node (Ollama)                 │
└───────────────────────────────────────────────────────────┘
```

### Edge Table

| From | To | Type |
|------|----|------|
| `START` | `market` | edge |
| `market` | `thesis` | edge |
| `thesis` | `verifier` | edge |
| `verifier` | `portfolio` | conditional (`verifier_passed == True`) |
| `verifier` | `END` | conditional (`verifier_passed == False`) |
| `portfolio` | `consistency_verifier` | edge |
| `consistency_verifier` | `explanation` | edge |
| `explanation` | `END` | edge |

⚠️ **Note:** In `graph_workflow.py`, a failed verification sends the workflow
straight to `END`. There is no retry loop. `main_langgraph.py` has a
`thesis_retry_node`, but it isn't wired the same way — see "Inconsistencies"
below.

## 3. State Schema

```python
class GraphState(TypedDict):
    tickers: List[str]                              # input: ["AAPL", "MSFT", "NVDA"]
    market_data: Dict[str, Dict[str, float]]        # {ticker: {price, return_1m}}
    thesis: dict[str, Any]                          # {"raw": str, "parsed": dict}
    verifier_passed: bool                           # gate for portfolio
    portfolio: Dict[str, float]                     # {ticker: weight_pct}
    portfolio_checks: Dict[str, Any]                # {"passed": bool, "issues": [...]}
    explanation: str                                # LLM narrative
```

### State Evolution

```
INIT
  tickers = ["AAPL", "MSFT", "NVDA"]
  (everything else empty)

  ▼ market_data_node
  market_data = {
      "AAPL": {"price": 227.5, "return_1m": 3.12},
      "MSFT": {"price": 415.2, "return_1m": -1.45},
      "NVDA": {"price": 138.9, "return_1m": 8.71},
  }

  ▼ thesis_node
  thesis = {
    "raw": '{"recommendations":[...]}',
    "parsed": {
      "recommendations": [
        {"ticker":"AAPL","recommendation":"Buy","confidence":0.312,"valuation_score":0.5},
        {"ticker":"MSFT","recommendation":"Hold","confidence":0.145,"valuation_score":0.5},
        {"ticker":"NVDA","recommendation":"Buy","confidence":0.871,"valuation_score":0.5}
      ]
    }
  }

  ▼ verifier_node
  verifier_passed = True

  ▼ portfolio_node
  portfolio = {"AAPL": 26.1, "MSFT": 12.2, "NVDA": 61.7}

  ▼ consistency_verifier_node
  portfolio_checks = {"passed": True, "issues": []}

  ▼ explanation_node
  explanation = "The portfolio allocates 61.7% to NVDA given its 8.71% ..."

END
```

## 4. Deterministic Rules (Source of Truth)

### `classify_recommendation(return_1m)`

| Condition | Label |
|-----------|-------|
| `< -5%` | Sell |
| `[-5%, 2%]` | Hold |
| `> 2%` | Buy |

### `compute_confidence(return_1m)`

```python
min(abs(return_1m) / 10, 1.0)
```

| 1m return | Confidence |
|-----------|-----------|
| 0% | 0.000 |
| 5% | 0.500 |
| 10%+ | 1.000 |

### `valuation_score_from_pe(pe)`

| P/E | Score |
|-----|-------|
| `< 20` | 0.8 |
| `< 35` | 0.6 |
| `>= 35` | 0.3 |
| `None` | 0.5 |

> 🐛 **Currently unused.** `market_data_node` never populates `pe_ratio`, so
> `info.get("pe_ratio")` always returns `None` and every valuation score is
> `0.5`. Add `stock.info.get("trailingPE")` to fix.

### Portfolio score

```
score = 0.5 · rec_score
      + 0.3 · confidence
      + 0.2 · valuation_score

rec_score ∈ {Sell: 1, Hold: 2, Buy: 3}
weight = score / Σ score · 100
```

### Consistency checks

| Check | Threshold |
|-------|-----------|
| Sum of weights | `abs(sum - 100) <= 1.0` |
| Sell weight | `<= 40%` |
| Buy weight | `>= 10%` |
| Low confidence + high weight | `conf < 0.30 AND weight > 35` |
| Pair-wise strength | stronger ticker shouldn't weigh 5%+ less |

## 7. Design Decisions

| Decision | Rationale |
|----------|-----------|
| **Deterministic thesis** | LLMs are unreliable at label + arithmetic consistency. Rules make results auditable and reproducible. |
| **LLM only for explanation** | LLM adds value narrating facts, not producing them. |
| **Two verifiers** | `verifier` protects the schema; `consistency_verifier` protects the portfolio math. |
| **`temperature=0`** | Deterministic LLM output for reproducible narratives. |
| **JSON round-trip in thesis** | `raw` + `parsed` lets the verifier re-parse independently (defense in depth). |
| **TypedDict state** | Type hints catch bugs in dev; LangGraph merges partial updates. |

## 8. Inconsistencies & Known Issues

### ⚠️ Two entry points diverge

- `app/graph_workflow.py` → 6 nodes, no retry, ends early on verifier fail.
- `main_langgraph.py` → 5 nodes, has `thesis_retry_node` but it isn't wired
  the same way and has no cap.

**Recommendation:** Delete `main_langgraph.py` or make it a thin wrapper that
just calls `graph_workflow.graph.invoke()`. Having two state schemas
(`GraphState` defined twice with different fields) is a bug waiting to happen.

### ⚠️ `pe_ratio` never populated

`thesis_node` looks up `info.get("pe_ratio")` but `market_data_node` never sets
it. Result: every valuation score defaults to `0.5`. Fix:

```python
info = stock.info
data[ticker] = {
    "price": ...,
    "return_1m": ...,
    "pe_ratio": info.get("trailingPE"),   # 🆕
}
```

### ⚠️ No retry cap if you reintroduce the loop

If you re-add `verifier → thesis` retry, add:

```python
class GraphState(TypedDict):
    ...
    iterations: int
```

And in `thesis_node`: `"iterations": state.get("iterations", 0) + 1`.
Then cap in the router: `if state["iterations"] >= 3: return END`.

### ⚠️ Module-level LLM

```python
llm = ChatOllama(model="llama3.2:3b", temperature=0)   # at import time
```

This runs on import — bad for testing, bad for Streamlit hot-reload,
and hard to swap models. Move it inside `build_graph()`:

```python
def build_graph(llm: ChatOllama | None = None):
    llm = llm or ChatOllama(model="llama3.2:3b", temperature=0)
    ...
```

### ⚠️ `verifier_node` mutates thesis

It returns `{"verifier_passed": True, "thesis": {"raw": raw, "parsed": parsed}}`
— writing back the same `thesis`. Harmless but redundant. Prefer to just
return `{"verifier_passed": True}` and let downstream nodes re-parse.

## 9. Extension Points

### Add a "news sentiment" node

1. Insert between `market` and `thesis`:
   `market → news_sentiment → thesis`
2. Extend `GraphState` with `sentiment: Dict[str, float]`
3. Fold sentiment into `thesis_node`'s scoring:
   `score = 0.4·rec + 0.25·conf + 0.2·val + 0.15·sentiment`

### Add fundamental data

Populate `pe_ratio`, `market_cap`, `dividend_yield` in `market_data_node` and
fold into a richer rule set.

### Structured LLM output

Replace `json.loads(response.content)` with:

```python
from pydantic import BaseModel

class Recommendation(BaseModel):
    ticker: str
    recommendation: Literal["Buy", "Hold", "Sell"]
    confidence: float
    reason: str

structured_llm = llm.with_structured_output(Recommendation)
```

(Only matters if you go back to LLM-generated theses.)

### Persistence

LangGraph supports checkpointing:

```python
from langgraph.checkpoint.memory import MemorySaver

graph = builder.compile(checkpointer=MemorySaver())
graph.invoke(input, config={"configurable": {"thread_id": "run-1"}})
```

### Parallelize market data fetch

Wrap `market_data_node` in `asyncio.gather` or Dask for large ticker lists.

## 10. Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| yfinance rate limits | Cache responses; add backoff |
| LLM invents numbers | Prompt says "do not change any numbers" — but add a post-check comparing numbers in `explanation` to `portfolio` |
| Verifier rejects valid JSON | Log `raw` on failure to inspect |
| `portfolio_checks` missing | `explanation_node` guards with `state.get(...)` default — good ✅ |
| Two entry points drift | Consolidate to one |

## 11. Glossary

| Term | Meaning |
|------|---------|
| **Node** | Python fn: `(state) → partial_update` |
| **Edge** | Always-followed directed connection |
| **Conditional edge** | Follows one of N targets depending on a router fn |
| **State** | `GraphState` TypedDict, merged after each node |
| **Compiled graph** | `builder.compile()` — the runnable |
| **Deterministic node** | Pure Python, no LLM |
| **LLM node** | Calls Ollama |
